AsyncStateMapBuilder

class AsyncStateMapBuilder<S, E, C, A, R>(val validStates: Set<S>, val name: String? = null, val parentBuilder: AsyncStateMachineBuilder<S, E, C, A, R>)

The builder of one state map for an asynchronous state machine. It is the suspend version of org.infosmid.kfsm.StateMapBuilder. It also records timeout transitions. The builder records all the transitions and actions of the state map. toMap() creates the immutable definition.

Parameters

validStates

The set of states that the state map allows.

name

The name of the state map. The name of the top-level state map is null.

parentBuilder

The builder of the state machine that owns this state map.

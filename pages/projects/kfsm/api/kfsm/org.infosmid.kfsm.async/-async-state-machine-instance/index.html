AsyncStateMachineInstance

class AsyncStateMachineInstance<S, E, C, A, R>(context: C, val definition: AsyncStateMachineDefinition<S, E, C, A, R>, val coroutineScope: CoroutineScope, initialState: S? = null, initialExternalState: ExternalState<S>? = null)

An instance of an asynchronous state machine. The instance processes events. It finds the matching transition and runs the exit action, the transition action and the entry action. The instance uses a CoroutineScope to run timeout transitions.

Parameters

context

The context that the actions operate on.

definition

The definition of the state machine. The definition has all the behaviour.

coroutineScope

The scope that runs the timeout transitions.

initialState

The state at the start. When it is null, the definition derives the state from the context.

initialExternalState

A state that was externalised earlier. Use it to restore the state map stack.

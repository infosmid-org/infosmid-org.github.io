AsyncDslStateMachineHandler

class AsyncDslStateMachineHandler<S, E, C, A, R>(fsm: AsyncStateMachineBuilder<S, E, C, A, R>)

The DSL receiver at the top level of an asynchronous state machine declaration. The actions are suspend functions. The state maps can have timeout transitions.

fun initialStates(deriveInitialMap: StateMapQuery<C, S>): AsyncDslStateMachineHandler<S, E, C, A, R>

Declares an expression that derives the state map stack from the context. The expression returns a list of pairs of a state and a state map name. The first pair is the bottom of the stack. The last pair is the current state map. Use it when the state machine has named state maps.

fun onStateChange(action: AsyncStateChangeAction<C, S>)

Declares an action that the state machine runs after the state has changed. The state machine does not run the action when the state stays the same. The state machine catches an exception from the action and does not rethrow it.

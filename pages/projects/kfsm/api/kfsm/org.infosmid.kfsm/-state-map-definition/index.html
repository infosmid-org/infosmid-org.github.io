class StateMapDefinition<S, E, C, A, R>(val name: String?, val validStates: Set<S>, val invariants: Set<Pair<String, Condition<C>>>, val transitionRules: Map<Pair<S, E>, SyncTransitionRules<S, E, C, A, R>>, val defaultTransitions: Map<E, DefaultSyncTransition<S, E, C, A, R>>, val entryActions: Map<S, DefaultEntryExitAction<C, S, A>>, val exitActions: Map<S, DefaultEntryExitAction<C, S, A>>, val defaultActions: Map<S, DefaultStateAction<C, S, E, A, R>>, val automaticTransitions: Map<S, SyncTransitionRules<S, E, C, A, R>>, val globalDefault: DefaultStateAction<C, S, E, A, R>?, val defaultEntryAction: DefaultEntryExitAction<C, S, A>?, val defaultExitAction: DefaultEntryExitAction<C, S, A>?, val afterStateChangeAction: StateChangeAction<C, S>?)

The definition of a state map. A state map is a group of states with their transitions and actions. A state machine has one top-level state map and can have named state maps.

Checks if an event is allowed in a state. The result is false when the state has no transition for the event. The exception is when includeDefault is true and the state has a default action or a default transition for the event.

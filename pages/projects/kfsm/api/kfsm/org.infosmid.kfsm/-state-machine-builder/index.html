StateMachineBuilder

class StateMachineBuilder<S, E, C, A, R>(validMapStates: Set<S>, validEvents: Set<E>)

The builder of a state machine definition. The DSL records the declaration in this builder. Then complete() creates the immutable definition.

Author

Corneil du Plessis

Parameters

validMapStates

The set of states that the default state map allows.

validEvents

The set of events of the state machine.

Type Parameters

S

The state type. It is often an enum.

E

The event type. It is often an enum.

C

The context type. The actions operate on the context.

A

The type of the event argument.

R

The type of the return value of the actions.

fun transition(startState: S, event: E, targetState: S, action: SyncStateAction<C, A, R>?)

Declares an external transition. The transition occurs when the current state is startState and the state machine receives the event. The state machine runs the exit action, the transition action and the entry action. Then the state changes to the target state.

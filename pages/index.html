Background & Mission

About infosmid.org

infosmid.org serves as the public open-source home for software created, maintained, and sponsored by infosmid.com.

Led by Corneil du Plessis, infosmid.com specializes in software architecture, enterprise application modernization, distributed event processing, and pragmatic engineering leadership. Tools created in the course of solving complex client architecture and delivery challenges are refined, documented, and released here under open licenses.

By publishing these solutions as open-source software, we maximize collective utility across the software engineering community — eliminating redundant effort and fostering reliable, reusable software components.

Core Commitments

  • Production-tested code
  • Permissive open-source terms
  • Zero unnecessary bloat
  • Direct GitHub issue tracking
  • Backed by consulting expertise
